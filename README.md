# Online Study Graduation Design

本科毕业设计项目整理版。

## 技术栈

- 后端：Spring Boot、MyBatis-Plus、Maven、MySQL
- 前端：Vue 2、Element UI、Axios
- 功能方向：在线学习 / 后台管理 / 前后端分离系统

## 主要内容

- 用户登录注册
- 权限与菜单管理
- 课程、文章、评论等业务模块
- 文件上传
- ECharts 数据展示
- 前台页面与后台管理页面
- 数据库 SQL 与部署/学习笔记

## 目录

- `src/`：Spring Boot 后端源码
- `vue/`：Vue 前端源码
- `sql/`：数据库脚本

## 说明

本分支是毕设项目的清洗整理版，已过滤学习笔记、`target`、`node_modules`、IDE 配置、编译产物和临时文件。
